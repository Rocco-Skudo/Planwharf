# Project instructions

Read and follow the root `AGENTS.md` before working in this repository.
After its required documentation reads, inspect `.agents/README.md` and
`.agents/SKILLS.md` and run `python .agents/check-updates.py` once at session
start. Report upstream updates or inability to check. Read relevant
`.agents/skills/<name>/SKILL.md` instructions before applying a skill.
Do not automatically install updates or overwrite local adaptations.
