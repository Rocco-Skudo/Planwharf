IMPLEMENTATION
One existing Audio instance and controller serve the selected project and all
views. A browser Web Lock enforces first-active-player ownership across tabs
and windows in the same browser profile and origin. A denied player remains
silent; it requires another explicit Play after the owner releases the lock.
Pause, Stop, Disable, Silence, end-of-playlist, media failure and page exit
release ownership. Pending acquisitions and cancelled local-file loads cannot
resurrect playback or retain an abandoned lock. No dependencies were added.

LIMITS
The ownership policy cannot span different profiles, browsers, hosts or ports.
Browsers without Web Locks support leave playback silent with a notice.
Tests and observation used isolated fixtures, not personal project data.
